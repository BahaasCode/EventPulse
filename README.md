## About

A full-stack event planning and analytics dashboard built with React, TypeScript, tRPC, and Drizzle ORM.

## Tech Stack

* **Frontend:** React 18, TypeScript, Vite, Tailwind CSS, shadcn/ui
* **Backend:** tRPC, Drizzle ORM, MySQL
* **Auth:** JWT + Zustand (local mock auth for offline use)
* **Charts:** Recharts

## Getting Started

1. Copy `.env.example` to `.env` and fill in your values
2. `npm install`
3. `npm run dev`

The app includes local mock authentication, you can register and log in without a database configured.
